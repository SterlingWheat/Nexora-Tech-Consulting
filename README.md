# NEXORA TECH CONSULTING

Consultora de tecnología orientada al diseño y desarrollo de soluciones de software web y móviles, aplicando buenas prácticas de ingeniería, calidad y gestión organizada de proyectos.

##  Objetivo

Desarrollar soluciones tecnológicas confiables y adaptadas a las necesidades de los clientes, manteniendo una adecuada gestión de requisitos, arquitectura, desarrollo, pruebas y documentación.
