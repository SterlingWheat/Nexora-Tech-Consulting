# Matriz de Trazabilidad Bidireccional de Requisitos

**Proyecto:** Sistema de Gestión de Voluntarios  
**Versión:** 1.0  
**Fecha:** 22 de septiembre de 2026  
**Documento base:** SRS v1.0 (ISO/IEC/IEEE 29148:2018)

Esta matriz vincula bidireccionalmente los Requisitos Funcionales (RF) y Requisitos No Funcionales (RNF) con sus fuentes de origen en los diagramas C4, las historias de usuario de gestión (Jira), los componentes de arquitectura y los casos de prueba de aceptación descritos con sintaxis Gherkin.

| Requisito (RF / RNF) | Fuente de Elicitación | Historia de Usuario Jira | Componente C4 | Caso de Prueba (Gherkin) |
| :--- | :--- | :--- | :--- | :--- |
| **RF-01** | Diagrama de Componentes | **Como** usuario del sistema, **quiero** autenticarme con mis credenciales **para** recibir un token JWT que valide mis peticiones. | Componente de Seguridad *(Spring Security)* | **Dado** un usuario con credenciales correctas, **cuando** envía la solicitud de login a la API, **entonces** recibe un token JWT firmado y válido. |
| **RF-02** | Diagrama de Componentes | **Como** sistema de seguridad, **quiero** verificar el rol en cada solicitud **para** denegar accesos no autorizados a servicios internos. | Componente de Seguridad *(Spring Security)* | **Dado** un usuario con rol de Voluntario, **cuando** intenta consumir un endpoint de Administrador, **entonces** el sistema responde con error 403 Forbidden. |
| **RF-03** | Diagrama de Contexto y Componentes | **Como** Administrador, **quiero** crear y actualizar voluntarios **para** mantener el padrón de datos personales al día. | Gestor de Voluntarios *(Spring Service)* | **Dado** un Administrador en la web, **cuando** envía el formulario con datos de un nuevo voluntario, **entonces** el Gestor persiste el registro en PostgreSQL. |
| **RF-04** | Diagrama de Contexto y Componentes | **Como** Administrador, **quiero** dar de alta nuevas tareas **para** organizar las labores del voluntariado. | Gestor de Tareas *(Spring Service)* | **Dado** un Administrador autenticado, **cuando** registra una tarea con título y descripción, **entonces** el Gestor de Tareas la guarda en la base de datos. |
| **RF-05** | Diagrama de Componentes | **Como** Administrador, **quiero** asignar voluntarios a tareas y actualizar su progreso **para** monitorear su avance operativo. | Gestor de Tareas *(Spring Service)* | **Dado** una tarea y un voluntario registrados, **cuando** el Administrador los vincula, **entonces** el Gestor de Tareas actualiza la asignación en PostgreSQL. |
| **RF-06** | Diagrama de Contexto y Componentes | **Como** Administrador, **quiero** planificar turnos según disponibilidad **para** programar la jornada de cada voluntario. | Gestor de Horarios *(Spring Service)* | **Dado** un voluntario con disponibilidad horaria, **cuando** el Administrador programa un turno, **entonces** el Gestor de Horarios persiste el turno asignado. |
| **RF-07** | Diagrama de Componentes | **Como** Administrador, **quiero** que el sistema impida solapamientos **para** evitar cruces de horarios en un mismo voluntario. | Gestor de Horarios *(Spring Service)* | **Dado** un voluntario con un turno ya asignado, **cuando** se intenta programar otro turno en el mismo horario, **entonces** la asignación es rechazada por cruce de horario. |
| **RF-08** | Diagrama de Componentes | **Como** Gestor de Tareas u Horarios, **quiero** solicitar avisos de asignación **para** armar las notificaciones que se enviarán al voluntario. | Gestor de Notificaciones *(Spring Service)* | **Dado** un turno o tarea confirmada, **cuando** se invoca el Gestor de Notificaciones, **entonces** este formatea la plantilla del correo con los datos de asignación. |
| **RF-09** | Diagrama de Contenedores y Componentes | **Como** Gestor de Notificaciones, **quiero** remitir correos vía SMTP a Gmail **para** que los avisos lleguen a la casilla del usuario. | Gestor de Notificaciones / Servicio de Email | **Dado** un mensaje estructurado, **cuando** el sistema se conecta por SMTP a Gmail, **entonces** el correo se despacha con acuse de entrega exitoso. |
| **RF-10** | Diagrama de Contexto y Contenedores | **Como** Voluntario, **quiero** consultar mis tareas y horarios desde mi celular **para** cumplir mis compromisos a tiempo. | Aplicación Móvil *(Flutter)* / API de Gestión | **Dado** un voluntario en la app Flutter, **cuando** entra a su cronograma, **entonces** la aplicación muestra sus tareas y turnos confirmados. |
| **RF-11** | Diagrama de Contexto y Contenedores | **Como** Voluntario, **quiero** consultar mis datos personales en la app móvil **para** revisar que mi información sea correcta. | Aplicación Móvil *(Flutter)* / Gestor de Voluntarios | **Dado** un voluntario en la app móvil, **cuando** ingresa a su perfil, **entonces** visualiza sus datos personales registrados. |
| **RF-12** | Diagrama de Contexto y Contenedores | **Como** Encargado de TI, **quiero** configurar parámetros del sistema **para** garantizar el soporte y mantenimiento de la plataforma. | Aplicación Web *(Vue.js)* / Base de Datos Principal | **Dado** un Encargado de TI en la web, **cuando** actualiza variables técnicas, **entonces** los cambios se persisten en la Base de Datos Principal. |
| **RNF-01** | Diagrama de Contenedores | **Como** usuario del sistema, **quiero** respuestas rápidas de la API **para** operar la plataforma sin demoras perceptibles. | API de Gestión *(Spring Boot)* | **Dado** un volumen de 100 peticiones concurrentes, **cuando** se consulta la API, **entonces** el tiempo de respuesta es menor o igual a 250 ms. |
| **RNF-02** | Diagrama de Contenedores y Componentes | **Como** Encargado de TI, **quiero** tráfico cifrado por HTTPS y autenticación JWT **para** evitar interceptaciones de información sensible. | Componente de Seguridad *(Spring Security)* | **Dado** un cliente web o móvil, **cuando** envía peticiones a la API, **entonces** viajan bajo HTTPS con un token JWT válido en los encabezados. |
| **RNF-03** | Diagrama de Contenedores | **Como** Administrador, **quiero** una interfaz web eficiente en Vue.js **para** programar asignaciones en pocos pasos. | Aplicación Web *(Vue.js)* | **Dado** un Administrador en la web, **cuando** asigna una tarea a un voluntario, **entonces** completa el flujo en un máximo de 4 clics. |
| **RNF-04** | Diagrama de Contenedores | **Como** Administrador, **quiero** alta disponibilidad del servicio **para** no perder continuidad en la gestión operativa. | API de Gestión / Base de Datos Principal | **Dado** el sistema en producción, **cuando** se mide el tiempo de actividad mensual, **entonces** registra un uptime igual o mayor al 99.5%. |
| **RNF-05** | Diagrama de Contenedores y Componentes | **Como** Encargado de TI, **quiero** un backend con pruebas automatizadas **para** garantizar un mantenimiento seguro y sin regresiones. | API de Gestión *(Spring Boot)* | **Dado** el pipeline de integración continua, **cuando** se ejecutan las pruebas del backend, **entonces** la cobertura de código alcanza al menos el 80%. |
